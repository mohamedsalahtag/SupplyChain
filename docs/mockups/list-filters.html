How it behaves (all lists)
  • Starts collapsed. The button shows how many filters are applied; the chips beside it name them — × removes one at once.
  • Changing a field changes nothing until Apply (or Enter). Clear all removes every filter; Close keeps what is applied.
  • Large lists (suppliers ~630, materials ~15,000) search as you type; materials and suppliers are looked up on the server, not loaded whole.
  • Applied filters are kept while you move to a record and back, and are in the page address, so a filtered list can be bookmarked or shared (closes backlog 37).
  • One shared component (ListFilters) so every list works the same; each page only lists its fields.
